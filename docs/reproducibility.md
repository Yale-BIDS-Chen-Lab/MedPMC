# Reproducibility

Reproducibility resources are organized by workflow:

- [Data curation](../data_curation/): stage-level processing and inference
- [Training](../training/): training recipes for MedPMC-CLIP and curation models
- [Evaluation](../evaluation/): curation-pipeline and downstream-model evaluation
- [Analysis](../analysis/): dataset analyses and visualizations

Each curation stage records its model identifier, dependencies, command-line configuration, output summaries, and manifest provenance.
